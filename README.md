A dynamic "made for you" web page — a personalized daily check-in experience combining a curated song grid, a rotating sketch prompt, and an interactive mood picker.

Live demo → https://akankhyaa.netlify.app/

What it does

  --A single-recipient personal page built around small daily interactions rather than static content:

 --A rotating song grid
 
 --A daily sketch prompt that loads dynamically
 
--An interactive mood check-in with clickable states and visual feedback

Tech stack

--HTML / CSS / JavaScript — no framework

--Custom typography and layout (Fraunces + DM Sans), styled as a warm, personal artifact rather than a generic template

What I built

Dynamic content loading (sketch prompts, song grid) instead of hardcoded static sections

Interactive state handling in vanilla JS — mood selection updates UI without a page reload

Custom illustrated/photo assets integrated into a cohesive visual identity
